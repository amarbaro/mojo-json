## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.

JSON for Mojo: a strict RFC 8259 parser and a writer whose output is byte for byte the same as Python's `json.dumps`, in the compact, default and indented layouts.

## Highlights

- `Json.items()` walks an array or object in one O(n) pass; an index loop over 100k elements took 8.8 s.
- A decoder or encoder crash is reported as FAIL by the checks, never as REJECT.

## Changes

### Added
- `Json.items()`: the elements of an array or the member values of an object, as copies, in one pass.
- Conda recipe (`recipe.yaml`) and a `mojo-upgrade` config.
- A property smoke step in the gate: `parse(dumps(x)) == x`.
- README install and quickstart block, one example, and badges for CI, latest release and license.

### Fixed
- `check_gen.sh` and the decoder check treat a decoder or encoder crash as FAIL, not REJECT.
